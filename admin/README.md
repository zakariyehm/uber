# Raac Operations (owner admin)

Dark command center for the Raac owner. Next.js + Tailwind on port **3100**, talking to Fastify on **3000**.

## Run

```bash
cd backend && npm run db:seed
cd backend && npm run dev
cd admin && npm run dev
```

Open http://localhost:3100
